# chaosformalbum

Галерея из двух страниц: вход по паролю и лента фотографий, по одной в ряд.
Фото, названия и звук скримера хранятся **зашифрованными**, поэтому репозиторий может быть публичным.

---

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `index.html` | Страница входа |
| `gallery.html` | Галерея |
| `assets/` | Стили, шрифт, звезда, рамка (`frame.png`), шифрование, встроенный звук скримера |
| `data/` | Зашифрованные фото, названия и настройки скримера (их пишет конструктор) |
| `tools/builder.html` | Конструктор (studio): всё редактирование галереи |

Посмотреть сайт до загрузки на GitHub: откройте `index.html` двойным щелчком.

---

## Как выложить на GitHub Pages

1. На github.com нажмите **New repository**, назовите, например, `chaosformalbum`, выберите **Public**, нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите **содержимое** этой папки (не саму папку): `index.html` должен оказаться в корне. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В **Source** выберите **Deploy from a branch**, ветка **main**, папка **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/chaosformalbum/`.

Свой домен подключается там же, в **Settings → Pages → Custom domain**. Оставьте галочку **Enforce HTTPS**: без https браузер не даст расшифровать фото.

## Конструктор: как менять галерею

Откройте `tools/builder.html` **в браузере** (двойной щелчок в Finder). В режиме предпросмотра (пробел в Finder) он не работает.
Если сайт уже на GitHub Pages, конструктор можно открыть и там: `…/chaosformalbum/tools/builder.html`.

### 1. Подключение: куда сохранять

- **GitHub** (рекомендуется). Изменения сразу уходят в репозиторий одним коммитом, сайт обновляется примерно через минуту, ничего не нужно загружать руками.
  Нужен токен:
  1. Откройте github.com → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
  2. **Repository access → Only select repositories** → выберите репозиторий сайта.
  3. **Permissions → Repository permissions → Contents → Read and write**.
  4. Нажмите **Generate token** и вставьте его в конструктор вместе с логином, названием репозитория и веткой (`main`).

  Токен хранится только в этом браузере. Кнопка **Forget token** его удаляет.
- **Folder on this computer**: конструктор пишет прямо в папку сайта на диске (Chrome и Edge). После этого изменённые файлы всё равно нужно загрузить на GitHub.
- **Download zip**: старый способ, скачивается `data.zip` и папка `data` заменяется вручную.

### 2. Что можно делать

1. **Current password**: посмотреть текущий пароль (кнопка **Show**). Конструктор помнит пароль только в этом браузере, если стоит галочка «Remember the password».
2. **Change password**: новый пароль применится при сохранении. Все фото перешифруются новым паролем.
3. **Photos**: порядок (↑ ↓), показать или спрятать (глаз), переименовать, удалить. Спрятанные фото остаются в архиве, но на сайте не показываются. Кавычки “…” вокруг названий сайт ставит сам.
4. **Add photos**: перетащить или выбрать файлы. Модель телефона, GPS и данные Photoshop вырезаются без пересжатия.
5. **Screamer**: картинка (любое фото галереи, в том числе спрятанное, или отдельный файл), звук (встроенный крик, свой файл до 4 МБ или без звука) и громкость. Кнопка **Test screamer** показывает результат.

Затем нажмите **Save to site** внизу экрана. Файлы удалённых фото удаляются сами.

## Что можно настроить в коде

- **Текст на входе**: `index.html`, блок `НАЗВАНИЕ И ТЕКСТ НА ВХОДЕ`.
- **Сторона звезды и подсказка в конце галереи**: `gallery.html`, блок `НАСТРОЙКИ`:

  ```js
  var CONFIG = {
    sigilSide: "right",   // звезда справа снизу ("right") или слева снизу ("left")
    endHint: "One more face hides behind the star"
  };
  ```
- **Цвета**: `assets/site.css`, блок `:root` (тёмно-зелёный: `--moss`, `--moss-hi`; названия фото: `--title`).
- **Рамка**: файл `assets/frame.png` (чёрная проволока на белом фоне). Положение задаётся в `assets/site.css`, блок «Рамка из колючей проволоки».

## Насколько это защищено

- Фото, названия и звук зашифрованы (AES-256, ключ из пароля). Без пароля это случайные символы, даже если скачать весь репозиторий.
- Защита ровно такая, как пароль: короткое слово можно подобрать перебором. Лучше пароль из 3–4 слов.
- Кто знает пароль, тот может сохранить фото (как минимум скриншотом).
- GitHub хранит историю всех коммитов. После смены пароля старые версии файлов в истории открываются **старым** паролем.
- Токен GitHub даёт запись в репозиторий. Создавайте его только для этого репозитория и не открывайте конструктор на чужих компьютерах.
- На страницах стоит запрет индексации для поисковиков.
